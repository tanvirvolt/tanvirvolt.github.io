Efficiency Improvement of an Induction Motor Using Advanced Control Techniques

This research project studies indirect field-oriented control (IFOC) for a three-phase induction motor using MATLAB/Simulink. The goal is to examine how decoupled flux and torque control can support controlled motor operation and how the inverter switching stage is driven by space-vector pulse-width modulation (SVPWM).

Control system overview

  1. Compare the reference speed with measured motor speed to generate the torque-producing current reference.
  2. Use d–q current regulation to manage flux-producing and torque-producing components.
  3. Estimate rotor flux and slip, then generate the electrical angle used for coordinate transformations.
  4. Transform current and voltage references between stationary and rotating reference frames.
  5. Use SVPWM switching commands to drive the voltage-source inverter connected to the induction motor.

Simulation focus

  • Speed-reference tracking and transient response.
  • Electromagnetic torque and stator-current behaviour.
  • Flux/torque decoupling in the field-oriented control structure.
  • Interaction between controller, inverter switching and motor dynamics.
